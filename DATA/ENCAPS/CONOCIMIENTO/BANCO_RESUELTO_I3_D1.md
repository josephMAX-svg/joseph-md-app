## 🟦 BLOQUE A — TIPOS DE VIGILANCIA (Q1–Q5)

### Q1 · ¿Qué distingue a la vigilancia de un simple registro? → **A**
A) Difusión de la info a los decisores para la acción de prevención/control · B) Almacenamiento en base nacional · C) Publicación anual de un boletín · D) Confirmación de laboratorio de todos los casos
**✅ A.** La vigilancia es **"información PARA LA ACCIÓN"**: no basta recolectar, hay que **analizar + DIFUNDIR al que decide** para intervenir.
**Cada alternativa:** A = el propósito real (difusión→acción). · B = eso lo hace también un registro (guardar datos ≠ vigilar). · C = un boletín es un producto, no la esencia. · D = la vigilancia NO exige confirmar todo por lab (existen casos probables).
**🎯 Gatillo:** *"El registro GUARDA, la vigilancia DEVUELVE el dato para actuar."*
**Tu D1:** A ✓ (posible suerte → reconfirmar en ciego).

### Q2 · Notifica solo lo que llega por demanda espontánea, sin buscar → **B (pasiva)**
A) Activa · B) Pasiva · C) Centinela · D) Comunitaria
**✅ B.** El EESS **espera** y reporta lo que llega; nadie sale a buscar.
**Cada alternativa:** A ACTIVA = el equipo SALE a buscar casos. · B PASIVA = el sistema espera la demanda espontánea (esta). · C CENTINELA = pocos EESS fijos con lab vigilan un evento. · D COMUNITARIA = ACS/comunidad vigilan donde no hay EESS.
**🎯 Gatillo:** *"¿Alguien salió a buscar? No → PASIVA."*
**Tu D1:** C ❌ (CCSN: confundiste pasiva con centinela).

### Q3 · El equipo acude, revisa historias, contacta lab, visita domicilios → **B (activa)**
A) Depende de la notificación espontánea · B) El equipo busca deliberadamente los casos, mejora la sensibilidad · C) Solo pocos establecimientos como muestra · D) Se basa en agentes comunitarios no profesionales
**✅ B.** Verbo de MOVIMIENTO (acude, revisa, contacta, visita) = **vigilancia ACTIVA**, maximiza SENSIBILIDAD.
**Cada alternativa:** A = describe la PASIVA (espontánea). · B = la ACTIVA (esta). · C = describe la CENTINELA. · D = describe la COMUNITARIA.
**🎯 Gatillo:** *"Activa = el AGENTE ANDA AFUERA A buscar."* (NO es "el sistema encendido").
**Tu D1:** A ❌ — **tu inversión #1**: marcaste la descripción de la PASIVA para una vigilancia ACTIVA. Tienes activa/pasiva cruzadas.

### Q4 · DIRESA vigila influenza en pocos EESS de referencia con laboratorio, para tendencias → **C (centinela)**
A) Pasiva universal · B) Comunitaria · C) Centinela · D) Activa domiciliaria
**✅ C.** "**Pocos** EESS de referencia **con lab** + **tendencias/agentes**" = definición de CENTINELA (muestra de calidad, no cobertura total).
**Cada alternativa:** A = pasiva universal (todos los EESS, cobertura). · B = comunitaria (ACS). · C = centinela (esta). · D = activa domiciliaria (ir casa por casa a captar TODOS).
**🎯 Gatillo:** *"Pocos centros fijos con lab para leer tendencias = CENTINELA."* (influenza/IRAG = ejemplo clásico).
**Tu D1:** D ❌ (CCSN: centinela ↔ activa).

### Q5 · Comunidad amazónica dispersa, ACS reportan signos de alarma → **C (comunitaria)**
A) Centinela (concentra en pocos puntos) · B) Pasiva institucional · C) Comunitaria (población/ACS donde el sistema no llega) · D) De laboratorio
**✅ C.** ACS + comunidad + zona sin EESS cercano = **COMUNITARIA** (extiende el alcance).
**Cada alternativa:** A = pocos EESS fijos (no ACS). · B = espera institucional. · C = comunitaria (esta). · D = depende de muestras de lab.
**🎯 Gatillo:** *"ACS / comunidad / zona sin posta = COMUNITARIA."*
**Tu D1:** C ✓ (posible suerte → reconfirmar).

> **RESUMEN DE VIGILANCIAS (memoriza esta línea):** PASIVA = el paciente entra, el sistema espera · ACTIVA = el equipo sale a buscar (sensibilidad) · CENTINELA = pocos EESS fijos con lab para tendencias · COMUNITARIA = ACS donde no hay posta · SINDRÓMICA = vigila síndromes antes del dx (alerta precoz).

## 🟩 BLOQUE B — DEFINICIÓN DE CASO Y NOTIFICACIÓN (Q6–Q8)

### Q6 · ¿Para qué es fundamental la definición de caso? → **B (estandarizar)**
A) Reemplazar el laboratorio · B) Estandarizar los criterios para que la notificación sea uniforme y comparable · C) Establecer el tratamiento · D) Determinar el presupuesto
**✅ B.** Estandariza **quién SE CUENTA como caso** → datos uniformes y **comparables** entre EESS.
**Cada alternativa:** A = no reemplaza al lab (los probables se confirman luego). · B = su función real (esta). · C = no dicta tratamiento. · D = no asigna presupuesto.
**🎯 Gatillo:** *"El CASO se define para CONTAR IGUAL, no para curar ni cobrar."* Palabra-clave: **estandarizar/comparable**.
**Tu D1:** D ❌ (Concepto: saltaste a "presupuesto" porque suena a gestión).

### Q7 · Caso probable vs confirmado → **A**
A) Probable = criterios clínicos y/o epidemiológicos; confirmado = además laboratorio positivo · B) Probable con lab, confirmado solo clínico · C) Son sinónimos · D) Confirmado solo por nexo sin lab
**✅ A.** El **LABORATORIO** es la frontera: sospechoso → probable (clínica/epi) → confirmado (**+lab**).
**Cada alternativa:** A = correcta. · B = invierte el lab. · C = falso (son niveles de certeza distintos). · D = el nexo epidemiológico confirma solo en ciertos protocolos, no "únicamente".
**🎯 Gatillo:** *"El LABo confirma."* Escalera: sospechoso → probable → confirmado.
**Tu D1:** A ✓ (posible suerte; en frío no distinguías sospechoso de probable → reconfirmar).

### Q8 · Notificación con datos nominales por cada individuo → **C (individual)**
A) Consolidada · B) Negativa · C) Individual · D) Agrupada
**✅ C.** Datos **nominales** (nombre, edad, dirección) por persona = notificación **INDIVIDUAL**.
**Cada alternativa:** A CONSOLIDADA = recuento agrupado por dx/edad/lugar (sin nombres). · B NEGATIVA = reportar **CERO casos** (lo OPUESTO a un caso). · C INDIVIDUAL = nominal, por persona (esta). · D "agrupada" = otro nombre de la consolidada.
**🎯 Gatillo:** *"Con NOMBRE → iNdividual · CERO casos → Negativa · por GRUPOS → Consolidada."*
**Tu D1:** B ❌ (CCSN: pusiste "negativa" —ausencia de casos— cuando había UN individuo concreto: son opuestos).

## 🟨 BLOQUE C — FLUJO, NOTIFICACIÓN OBLIGATORIA Y PLAZOS (Q9–Q12)

### Q9 · Mínima unidad notificante del sistema → **B (EESS)**
A) Microrred · B) Establecimiento de Salud (EESS) · C) Red · D) DIRESA/GERESA
**✅ B.** El dato **NACE en el EESS** (donde se atiende al paciente). Flujo ASCENDENTE: EESS → Microrred → Red → DIRESA/GERESA → DGE/CDC.
**Cada alternativa:** A/C = niveles intermedios (agregan, no son el mínimo). · B = la unidad mínima (esta). · D = nivel regional (techo intermedio), NO el piso.
**🎯 Gatillo:** *"El humo nace ABAJO (EESS) y SUBE."* Un puesto I-1 rural notifica igual que un hospital de Lima.
**Tu D1:** D ❌ — **tu inversión #3**: pusiste el techo (DIRESA) como si fuera el piso.

### Q10 · Semana sin casos: no envía reporte "porque no hubo nada" → **B (incorrecto: notificación negativa)**
A) Correcta, solo se notifica con casos · B) Incorrecta: debe hacer notificación negativa (cero casos) para evitar el silencio epidemiológico · C) Correcta si avisa verbal a la microrred · D) Incorrecta: esperar el cierre mensual
**✅ B.** Sin casos IGUAL se notifica **"cero"** (negativa); callar = **silencio epidemiológico** (puede ocultar un brote).
**Cada alternativa:** A = falso (siempre se reporta). · B = correcta (esta). · C = "verbal" no sustituye el reporte formal. · D = la negativa es en el mismo periodo, no se difiere al mes.
**🎯 Gatillo:** *"Ausencia de reporte ≠ ausencia de enfermedad. Sin casos → mando el CERO."*
**Tu D1:** C ❌ (Concepto: no sabías la regla de notificación negativa).

### Q11 · Notificación inmediata según Directiva 046 → **A (24h vía RENACE)**
A) Dentro de 24 h, flujo ascendente por la RENACE · B) Hasta 30 días con el consolidado mensual · C) Anual al INS · D) Flujo descendente desde el nivel nacional
**✅ A.** Inmediata = **<24 h**, ascendente por la **RENACE**. Base: **Directiva Sanitaria 046-MINSA/DGE-V.01 (RM 506-2012)**.
**Cada alternativa:** A = correcta. · B = eso es lo semanal/consolidado, no lo inmediato. · C = falso. · D = el flujo SUBE, no baja.
**🎯 Gatillo:** *"Inmediata = 24h, sube por RENACE. (Directiva 046 / RM 506-2012, NO 067/2020)."*
**Tu D1:** A ✓ — el único acierto "firme" candidato; **vigilar**: si re-falla en ciego, será la 1ª tarjeta Anki.

### Q12 · Muerte materna en primer nivel → **B (inmediata + investigar)**
A) Esperar el consolidado mensual · B) Notificar inmediata (evento obligatorio) + investigar el caso · C) Solo libro de partos, sin notificar · D) Solo si la causa fue directa (obstétrica)
**✅ B.** Muerte materna = evento **centinela** → notificación **INMEDIATA (<24h) + INVESTIGACIÓN** (causas directas E indirectas; "tres demoras").
**Cada alternativa:** A = no se difiere. · B = correcta (esta). · C = certificar no basta. · D = también se vigilan las indirectas (cardiopatía, TB, VIH agravadas por el embarazo).
**🎯 Gatillo:** *"Toda muerte materna: inmediata + INVESTIGAR (directa e indirecta)."*
**Tu D1:** C ❌ (Concepto: no la reconociste como evento de notificación obligatoria).

## 🟧 BLOQUE D — ESCALA: ENDEMIA / BROTE / EPIDEMIA / PANDEMIA (Q13–Q14)

### Q13 · Malaria vivax habitual y estable año a año en la zona → **C (endemia)**
A) Epidemia · B) Pandemia · C) Endemia · D) Brote
**✅ C.** "Habitual, estable, esperado" = **ENDEMIA** (nivel basal), aunque sean muchos casos.
**Cada alternativa:** A EPIDEMIA = por ENCIMA de lo esperado. · B PANDEMIA = varios países. · C ENDEMIA = lo habitual/esperado (esta). · D BROTE = ≥2 casos con nexo.
**🎯 Gatillo:** *"¿Superan LO ESPERADO? No → ENDEMIA (aunque sean hartos)."*
**Tu D1:** A ❌ (CCSN: endemia ↔ epidemia).

### Q14 · Tres familiares con diarrea aguda en 48h tras un almuerzo comunal → **B (brote)**
A) Endemia estacional · B) Brote · C) Pandemia · D) Caso índice aislado
**✅ B.** **≥2 casos con NEXO** (misma familia, mismo almuerzo, mismo tiempo) = **BROTE**.
**Cada alternativa:** A = presencia habitual (no aplica a un evento agudo). · B = brote (esta). · C = varios países (absurdo para 3 personas en una casa). · D = "aislado" contradice el nexo entre los 3.
**🎯 Gatillo:** *"2+ casos ligados por tiempo/lugar/comida = BROTE."* (En enfermedad erradicada, 1 caso ya es brote).
**Tu D1:** C ❌ (CCSN de escala extrema: brote ↔ pandemia).

> **ESCALERA (memoriza): "En Bici Entro al País" → Endemia (casa) · Brote (cuadra, con nexo) · Epidemia (región, sobre lo esperado) · Pandemia (varios países).**

## 🟥 BLOQUE E — PASOS DE BROTE E INDICADORES (Q15, Q17, Q18)

### Q15 · Etapa INICIAL de la investigación de un brote (antes de las hipótesis) → **C**
A) Implementar control definitivo y evaluar impacto · B) Redactar el informe final · C) Verificar el diagnóstico y confirmar la existencia del brote · D) Estudio analítico de casos-controles
**✅ C.** Primero se **CONFIRMA el brote + se VERIFICA el diagnóstico**; luego hipótesis → analítico → control definitivo → informe.
**Cada alternativa:** A = paso FINAL (control definitivo/impacto). · B = paso FINAL (informe). · C = paso INICIAL (este). · D = paso MEDIO (prueba la hipótesis).
**🎯 Gatillo:** *"CO-VE antes de HI"* (Confirmar + Verificar antes de la Hipótesis). "Controlar/evaluar/informar" = siempre el final.
**Tu D1:** A ❌ (Cronología: pusiste un paso final como inicial).

### Q17 · 50 enfermos de 200 asistentes a un evento → **B (tasa de ataque)**
A) Prevalencia · B) Tasa de ataque · C) Letalidad · D) Mortalidad general
**✅ B.** Casos / **EXPUESTOS** en población cerrada de un brote = **TASA DE ATAQUE** (50/200 = 25%).
**Cada alternativa:** A PREVALENCIA = casos existentes/población (no brote agudo). · B TASA DE ATAQUE = casos/expuestos (esta). · C LETALIDAD = muertes/casos (no hay muertes aquí). · D MORTALIDAD = muertes/población.
**🎯 Gatillo:** *"Enfermos entre EXPUESTOS del evento = tasa de ataque."* Si no mencionan muertes, no es letalidad ni mortalidad.
**Tu D1:** D ❌ (Concepto/CCSN de indicador).

### Q18 · 400 casos, 20 fallecidos → letalidad → **C (5%)**
A) 0,5% · B) 2% · C) 5% · D) 20%
**✅ C.** Letalidad = muertes / **CASOS** ×100 = 20/400 = **5%**.
**Cada alternativa:** A = error de cálculo. · B = 2% sería mortalidad (20/1000, ÷población) — el distractor. · C = 5% correcta (÷casos). · D = 20% invierte la fracción.
**🎯 Gatillo:** *"LEtalidad ÷ CAsos (los que YA cayeron enfermos). Mortalidad ÷ Población."* Te ponen el 2% al lado del 5% a propósito.
**Tu D1:** B ❌ — **tu inversión #2**: usaste denominador de mortalidad (población) en vez de casos.

## 🟪 BLOQUE F — CANAL ENDÉMICO Y ATRIBUTOS DEL SISTEMA (Q16, Q19, Q20)

### Q16 · Línea central del canal/corredor endémico → **B (mediana 5-7 años)**
A) Media aritmética · B) Mediana de los últimos 5-7 años · C) Moda del año previo · D) Promedio ponderado del trimestre
**✅ B.** Se usa la **MEDIANA** de una serie de **5-7 años** porque **resiste los años epidémicos** (valores extremos).
**Cada alternativa:** A MEDIA = se infla con los brotes previos (haría pasar un brote por normal). · B MEDIANA = robusta (esta). · C MODA = inestable con datos semanales. · D = promedio corto, no capta el patrón histórico.
**🎯 Gatillo:** *"La MEDIANA aguanta el brote; la media se deja arrastrar."*
**Tu D1:** C ❌ (Concepto: asociaste "lo habitual" con moda; la trampa fuerte era la media).

### Q19 · Uso del corredor endémico en la sala situacional → **B (observado vs esperado)**
A) Reemplazar el análisis de determinantes · B) Comparar los casos observados de la semana con el comportamiento esperado histórico, para detectar desviaciones y actuar · C) Calcular la letalidad del próximo año · D) Estimar la prevalencia de crónicas
**✅ B.** Compara **OBSERVADO (hoy) vs ESPERADO (histórico)** → detección **OPORTUNA** de brotes. No predice el futuro.
**Cada alternativa:** A = no reemplaza determinantes. · B = su uso real (esta). · C = no proyecta letalidad. · D = no mide prevalencia de crónicas.
**🎯 Gatillo:** *"Corredor = comparar el PRESENTE contra el PASADO típico, por 4 zonas (éxito/seguridad/alarma/epidemia)."*
**Tu D1:** C ❌ (Concepto).

### Q20 · Muchos notificados como dengue que NO confirman → **D (VPP bajo)**
A) Sensibilidad · B) Oportunidad · C) Representatividad · D) Valor predictivo positivo (VPP)
**✅ D.** Muchos notificados que no confirman = **falsos positivos** = **VPP bajo** (problema de EXACTITUD).
**Cada alternativa:** A SENSIBILIDAD = capacidad de detectar los casos verdaderos (no perderlos). · B OPORTUNIDAD = rapidez (tiempo evento→acción). · C REPRESENTATIVIDAD = si cubre a toda la población/geografía. · D VPP = de lo notificado, cuánto era verdad (este).
**🎯 Gatillo:** *"No confirman/falsos positivos → VPP. Llegó tarde → oportunidad. Se escapan → sensibilidad."* **VPP = Verdad Post-notificar** (mira exactitud, no reloj).
**Tu D1:** B ❌ — **tu inversión #4**: VPP (exactitud) ↔ oportunidad (velocidad).
