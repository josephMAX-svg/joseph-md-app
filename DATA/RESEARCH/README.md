# DATA · RESEARCH (revisiones sistemáticas → Mayo / Bioclinic)

Carpeta de la sección **Research**. Spec maestra: [`../../MD_MAESTRO_BIOCLINIC_RESEARCH.md`](../../MD_MAESTRO_BIOCLINIC_RESEARCH.md)
(visión Mayo/Bioclinic, líneas 0–8, motor de publicación, sistema agéntico, roadmap).
Aquí se **guarda la data investigada** y el plan día-a-día de research.

## Foco
- **Revisiones sistemáticas** (no investigación general): es el camino más rápido a PIPs
  porque **no requieren comité de ética** y se hacen con datos públicos.
- **Línea énfasis:** dermatología **estética estructural** (Líneas 1–4, 7).
- **Meta dura:** ~3 PIPs para competir · 8–15 nivel Mayo · ≥3 SR/meta-análisis.
- **Contexto temporal:** España (MIR 2030–2034) → fellowship dermatología EE.UU. (Mayo/
  Bioclinic) → residencia. Estándares muy altos para IMG (ver §1.3 *reality check* del MD).

## Qué guardar aquí (estructura sugerida)
```
RESEARCH/
  README.md                 (este archivo)
  journals.md               revistas top verificadas (IF, cuartil, gratis/APC waiver LMIC, requisitos)
  systematic-reviews.md     playbook PRISMA/PROSPERO/GRADE + herramientas + recursos YouTube
  lines/                    una sub-ficha por línea de investigación (L0–L8)
  agentic/                  diseño del sistema agéntico (orquestador + subagentes + .docx)
  daily-plan.md             plan día-a-día (interdiario con Dermatología): qué hacer cada día
  benchmarks.md             cuántas publicaciones/SR para match derma EE.UU. + Mayo (honesto)
```

## Encargo del chat de Research
1. **Revisar cómo construyen los referentes** (YouTube/web) una revisión sistemática paso a
   paso → guardar recursos con **URLs reales verificadas** (cada botón de la app debe
   enlazar a un sitio real, nunca un placeholder).
2. **Revistas top:** cuáles son, **en cuáles se publica gratis** (Diamond OA / waiver LMIC
   para Perú) y sus **requisitos**; con cuántas SR/publicaciones se aplica a Mayo dermatología.
3. **Plan día-a-día** (interdiario con Derma) con el mismo motor de estudio + links/vídeos reales.
4. **Sistema agéntico** (orchestrator-worker + HITL): un agente dirige una línea, subagentes
   redactan intro/métodos/resultados/discusión/referencias, QA verifica citas, y se ensambla
   un **Word (.docx)** automáticamente; Joseph solo verifica el Word final.
5. Mejorar/ampliar `MD_MAESTRO_BIOCLINIC_RESEARCH.md` con lo verificado y dejar la data aquí.

> El bloque de investigación verificada (revistas, SR, benchmarks Mayo, sistema agéntico)
> se añade como apéndice a `MD_MAESTRO_BIOCLINIC_RESEARCH.md` (ver "Apéndice verificado").
